This texture pack was created using a limited color palette inspired by classic monochrome handheld gaming systems made in Japan. It is designed for MTG and officially provides support for the following mods:
* Base Pack
* Beds
* Binoculars
* [Bone Meal](https://content.luanti.org/packages/TenPlus1/bonemeal/)
* Bones
* Bucket
* Butterflies
* Carts
* Default
* Doors
* Dye
* Farming
* [Fingore](https://content.luanti.org/packages/Ludus/fingore/)
* Fire
* Fireflies
* Flowers
* Keys
* [Loose Rocks](https://content.luanti.org/packages/eduardomezencio/loose_rocks/#description)
* Map
* [Metallicum](https://content.luanti.org/packages/Ludus/metallicum/)
* Mtg Craftguide
* Player Api
* [Schemedit](https://content.luanti.org/packages/Wuzzy/schemedit/)
* Screwdriver
* Stairs
* Tnt
* Vessels
* Wool
* Xpanes

I Recommend the [Sky Color mod](https://content.luanti.org/packages/Ludus/color_sky/) made by me, as this texture pack does not modify the default sky.

If you don't like the textures, feel free to submit a pull request on GitHub.
